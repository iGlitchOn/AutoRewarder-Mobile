# AutoRewarder Mobile

**AutoRewarder by iGlitchOff** — Android companion for Microsoft Rewards (check-in, news, pair with the PC app).

## Download

Get `AutoRewarder.apk` from **[Releases](https://github.com/iGlitchOn/AutoRewarder-Mobile/releases)**.

Install it on your phone, then in the PC app: Account → Link a phone → scan the QR or type the 6-digit code **inside this app** (not in Chrome).
